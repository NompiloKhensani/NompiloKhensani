### 👩🏽‍💻 About Me

I'm a Full Stack Web Developer from **Pretoria, South Africa**, with a Bachelor of Commerce in Financial Sciences and a Postgraduate Diploma in Internal Auditing. My academic background strengthened my analytical thinking, attention to detail and understanding of business processes, which I apply when analysing requirements, solving problems and developing software solutions.

I completed my Full Stack Web Development training at Zaio Institute of Technology, gaining hands-on experience with React, JavaScript, Node.js, Express.js and MongoDB. I've built projects ranging from a full-stack Airbnb clone and an Amazon-inspired e-commerce application to an interactive TicTacToe game. I enjoy working across the development stack, from creating responsive user interfaces to developing backend functionality, integrating APIs and managing databases.

- 🔭 Currently developing **Kitchen Kronikles**, a recipe-focused application, while continuing to expand my portfolio.
- 🌱 Continuously improving my knowledge of React, Node.js, backend development and application architecture.
- 💡 Interested in software development roles, emerging technologies and building applications that solve practical problems.
- 🍰 Random fact: When I'm not coding, I'm experimenting with recipes in the kitchen as a self-taught baker.
